## Implemented scope
- Strict bounded UTF-8 JSON parser rejecting duplicate keys, non-finite values, excessive size and nesting.
- Canonical UTF-8 JSON serialization and SHA-256 digests.
- Exact-field runtime validation for request v1 and the core capability argument shapes.
- TTL/expiry/future-clock rules including the shorter visual-capture lifetime.
- Safe mailbox-relative path validation, including Windows drive/UNC/traversal/ADS rejection.
- Response/artifact/index/session-event/config-envelope validators and payload byte/digest verification.
- Draft 2020-12 portable JSON Schemas for all v1 envelope types.
