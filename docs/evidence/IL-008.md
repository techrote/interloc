## Implemented scope
Strict local enrollment and request import; request previews; interactive full-
digest confirmation; durable denial/revocation; read-only doctor/status; durable
pause/resume. Local imports and trusted transport ingestion use one control
service. Default CLI target resolution supports ping only and fails closed for
unwired providers. Fake enrolled target providers test the shared interface.

Broker schema v2 adds durable authority/approval binding and pause state. Short
explicit SQLite transactions replace ineffective autocommit context blocks.
Intake plus binding, confirmation plus consent storage, collision quarantine,
and concurrent queue admission are atomic. Execution checks current authority,
request expiry and pause before starting. Interrupted handlers retain the
broker's indeterminate-recovery semantics. Running handlers and human prompts
never hold the writer transaction.
