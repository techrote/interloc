### Greenshot interface facts checked 2026-09-13

Current Greenshot source inspected at `greenshot/greenshot@a439c69e34c0eefce4ec9c5525938a0d802fbc1d`:

- `ICoreConfiguration.WindowHotkey` defaults to `Alt + PrintScreen`.
- `CaptureWindowsInteractive` defaults to `false`, meaning the window hotkey captures the active window rather than entering interactive selection.
- `OutputDestinations` supports `FileDefault`; its default is `Picker`.
- `OutputFilePath` and `OutputFileFormat` are explicit configuration values; default output format is PNG.
- The current Greenshot command-line parser exposes exit/reload/no-run/language/INI-directory/image-open operations, **not** a capture-window-to-file command.

Therefore IL-013 must not invent a nonexistent Greenshot capture CLI. The interim provider is permitted to use a **single fixed local hotkey-injection path solely to invoke Greenshot's configured window-capture hotkey after Interloc consent and target validation**. This is not a general keyboard capability and must not accept requester-supplied key sequences.

### Required Greenshot MVP boundary for IL-013

The production adapter must:

- require an explicitly enrolled/approved target window and revalidate HWND, PID and process-creation identity immediately before capture;
- require the approved target to already be the foreground window; it must not focus or activate arbitrary windows;
- accept only a tightly bounded Greenshot window hotkey ending in `PrintScreen` (default `Alt + PrintScreen`), with no arbitrary key injection;
- require `CaptureWindowsInteractive=false` so capture is not redirected to an interactive picker;
- require Greenshot direct-file output (`FileDefault`) and PNG output into a locally configured watched directory; otherwise fail with an actionable diagnostic;
- never read the clipboard, never use full-desktop capture, and never silently fall back to another capture backend;
- wait for exactly one new/updated PNG within a bounded timeout, reject ambiguous/multiple outputs, validate PNG dimensions/size, hash the exact bytes, and retain only local artifact metadata until a later delivery step;
- keep raw screenshots local and outside the source repository.

If the installed Greenshot configuration cannot meet these conditions, the adapter reports unavailable rather than mutating Greenshot configuration or weakening Interloc policy.

## Security consequence

The repository-wide prohibition on **general** key/mouse injection remains. The Greenshot MVP is a narrow exception implemented internally by the capture provider: a fixed, locally read Greenshot window-capture chord only, after target/consent checks. No request schema gains key names, virtual-key codes, arbitrary hotkeys or general input authority.
