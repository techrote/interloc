# Ordinary-Chat transport feasibility notes

IL-020 intentionally contains **no browser automation code**.

Current decision (2026-09-13): no provider-supported ordinary consumer-Chat terminal/API transport was established from primary OpenAI documentation. Codex CLI is a Codex surface and therefore does not meet the project requirement. The current UK-applicable individual Terms prohibit automatic/programmatic extraction of data or Output, so assistant-reply DOM scraping is not an acceptable experimental shortcut.

The manual Interloc handoff remains the implementation baseline. IL-022 is conditional on a future positive `G-assisted` decision backed by a supported route or explicit permission; technical ability to manipulate a browser DOM is not sufficient evidence.

See `docs/evidence/IL-020.md` for dated sources and the route matrix.
